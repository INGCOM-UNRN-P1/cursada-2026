# Prácticas y Entregas (2026)

Este año, la cátedra incorporó una biblioteca de testing con aserciones (`p1_test` / `libtest`) para facilitar la verificación del código y la confección de pruebas unitarias. No estuvo disponible desde el principio, sino que fue incorporada gradualmente a medida que avanzaban los temas.
