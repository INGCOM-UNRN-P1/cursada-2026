## Bibliotecas Estáticas

### 1. `libdinamicos`: Arreglo Dinámico Encapsulado

Encapsula un bloque de memoria contigua en heap de enteros con redimensionamiento geométrico automático.

#### Estructura de Datos

```c
typedef struct arreglo_dinamico {
    int *datos;         /**< Puntero al bloque contiguo en heap */
    size_t cantidad;    /**< Cantidad actual de elementos almacenados */
    size_t capacidad;   /**< Capacidad física total reservada en memoria */
} arreglo_dinamico_t;
```

| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `datos` | `int *` | Puntero a la memoria asignada dinámicamente en el heap. |
| `cantidad` | `size_t` | Cantidad de elementos enteros válidos almacenados. |
| `capacidad` | `size_t` | Capacidad física total reservada (alcanza para `capacidad` enteros sin realocar). |

#### Contratos de la API (`dinamicos.h`)

- `bool arreglo_dinamico_crear(arreglo_dinamico_t *arreglo, size_t capacidad_inicial);`  
  Inicializa `arreglo` reservando espacio para `capacidad_inicial` enteros. Si `capacidad_inicial == 0`, asigna una capacidad mínima por defecto (4). Retorna `false` ante puntero nulo o fallo de `malloc`.
- `void arreglo_dinamico_destruir(arreglo_dinamico_t *arreglo);`  
  Libera la memoria de `datos` en heap y resetea `cantidad` y `capacidad` a 0. Tolera punteros `NULL` o llamadas repetidas sin errores.
- `bool arreglo_dinamico_agregar(arreglo_dinamico_t *arreglo, int valor);`  
  Agrega `valor` al final. Si `cantidad == capacidad`, duplica la capacidad mediante `realloc`. Retorna `false` si falla la asignación.
- `int *arreglo_dinamico_obtener(const arreglo_dinamico_t *arreglo, size_t indice);`  
  Retorna un puntero al elemento en `indice`. Si `arreglo == NULL` o `indice >= cantidad`, retorna `NULL`.
- `bool arreglo_dinamico_filtrar_pares(const arreglo_dinamico_t *origen, arreglo_dinamico_t *destino);`  
  Crea e inicializa `destino` con los elementos pares de `origen` preservando el orden original.
- `int arreglo_dinamico_buscar(const arreglo_dinamico_t *arreglo, int valor);`  
  Retorna el índice 0-based de la primera aparición de `valor`, o `-1` si no existe o ante parámetros inválidos.
- `void arreglo_dinamico_invertir(arreglo_dinamico_t *arreglo);`  
  Invierte los elementos del arreglo *in-place*. Sin efecto si `arreglo == NULL` o `cantidad <= 1`.
- `size_t arreglo_dinamico_compactar(arreglo_dinamico_t *arreglo, int valor);`  
  Elimina todas las ocurrencias de `valor` desplazando los elementos contiguos sin dejar huecos. Retorna la cantidad de elementos eliminados.

### 2. `libcadena_segura`: Cadena Dinámica Segura

Encapsula cadenas de caracteres terminadas en `\0` en el heap, rastreando su longitud efectiva y capacidad reservada para evitar desbordes de buffer (*buffer overflow*).

#### Estructura de Datos

```c
typedef struct cadena_segura {
    char *texto;       /**< Puntero al búfer de caracteres en heap */
    size_t longitud;   /**< Longitud de la cadena (sin contar '\\0') */
    size_t capacidad;  /**< Tamaño total reservado en heap */
} cadena_segura_t;
```

| Campo | Tipo | Descripción |
| :--- | :--- | :--- |
| `texto` | `char *` | Cadena en heap garantizada con terminador nulo (`\0`). |
| `longitud` | `size_t` | Cantidad de caracteres útiles (equivalente a `strlen(texto)`). |
| `capacidad` | `size_t` | Bytes asignados en heap (siempre `>= longitud + 1`). |

#### Contratos de la API (`cadena_segura.h`)

- `bool cadena_segura_crear(cadena_segura_t *cadena, const char *literal);`  
  Inicializa `cadena` copiando el contenido de `literal`. Si `literal == NULL`, crea una cadena vacía (`""`). Retorna `false` ante error de asignación o puntero nulo.
- `void cadena_segura_destruir(cadena_segura_t *cadena);`  
  Libera el buffer `texto` en heap y resetea `longitud` y `capacidad` a 0. Operación segura ante punteros `NULL`.
- `bool cadena_segura_concatenar(cadena_segura_t *cadena, const char *sufijo);`  
  Anexa `sufijo` al final de `cadena`. Si la longitud resultante excede la capacidad disponible, redimensiona el bloque en heap.
- `bool cadena_segura_subcadena(const cadena_segura_t *origen, size_t inicio, size_t longitud, cadena_segura_t *destino);`  
  Extrae hasta `longitud` caracteres a partir del índice `inicio` y genera una nueva `cadena_segura_t` en `destino`.
- `bool cadena_segura_clonar(const cadena_segura_t *origen, cadena_segura_t *destino);`  
  Crea una copia profunda (*deep copy*) e independiente de `origen` en `destino`.
- `int cadena_segura_buscar(const cadena_segura_t *cadena, const char *aguja);`  
  Busca la primera aparición de la subcadena `aguja`. Retorna el índice 0-based de inicio, o `-1` si no coincide o parámetros inválidos.

## Consignas de los Ejercicios de Aplicación

### Ejercicio 1: Procesamiento de Flujo de Telemetría (`ejercicios/ejercicio1`)

Implementar el módulo [`sensor_flujo.h`](ejercicios/ejercicio1/sensor_flujo.h) para procesar secuencias continuas de mediciones tomadas por sensores de campo:

- `bool cargar_muestras(arreglo_dinamico_t *muestras, const int *valores, size_t n);`  
  Carga un lote de `n` mediciones en el arreglo dinámico `muestras`.
- `double calcular_promedio(const arreglo_dinamico_t *muestras);`  
  Calcula el promedio aritmético de las muestras registradas. Retorna `0.0` si no hay lecturas o el puntero es nulo.
- `size_t depurar_lecturas_erroneas(arreglo_dinamico_t *muestras, int codigo_error);`  
  Elimina todas las lecturas centinela que coincidan con `codigo_error` (por ejemplo `-999` por falla de sonda) compactando el arreglo con `arreglo_dinamico_compactar`.
- `bool extraer_eventos_pares(const arreglo_dinamico_t *muestras, arreglo_dinamico_t *eventos);`  
  Extrae a un nuevo arreglo dinámico `eventos` todas las lecturas de telemetría de valor par mediante `arreglo_dinamico_filtrar_pares`.

---

### Ejercicio 2: Generador de Slugs Web y Sanitización (`ejercicios/ejercicio2`)

Implementar el módulo [`slug_generator.h`](ejercicios/ejercicio2/slug_generator.h) para transformar títulos arbitrarios en identificadores amigables para URL (slugs):

- `bool generar_slug(const cadena_segura_t *titulo, cadena_segura_t *slug);`  
  Normaliza `titulo` convirtiendo mayúsculas a minúsculas, sustituyendo caracteres no alfanuméricos por guiones (`-`), y colapsando múltiples guiones consecutivos en uno solo, sin guiones al inicio ni al final.
- `bool contiene_palabra_prohibida(const cadena_segura_t *texto, const char *palabra);`  
  Verifica si el texto contiene una palabra no permitida o término prohibido utilizando `cadena_segura_buscar`.
- `bool acotar_longitud_slug(cadena_segura_t *slug, size_t max_longitud);`  
  Recorta la longitud máxima del slug generado empleando `cadena_segura_subcadena`, asegurando que el slug resultante no finalice con un guion cortado.

- **[0x3001h](https://ingcom-unrn-p1.github.io/indice-1/)**: Verificación inmediata y defensiva del resultado de `malloc` y `realloc`.

- **[0x3008h](https://ingcom-unrn-p1.github.io/indice-1/)**: Inicialización y comparación de punteros nulos contra `NULL` (nunca contra `0`).
- **[0x300Bh](https://ingcom-unrn-p1.github.io/indice-1/)**: Uso estricto de `sizeof` sobre el tipo o variable en asignaciones dinámicas.
- **[0x300Eh](https://ingcom-unrn-p1.github.io/indice-1/)**: Documentación y gestión defensiva ante punteros nulos recibidos como parámetros.

## Comandos de Compilación y Verificación

- **Compilar todo el proyecto (librerías y programas)**:
  ```bash
  make all
  ```

- **Ejecutar todos los programas de aplicación**:
  ```bash
  make run
  ```

- **Ejecutar las suites de pruebas unitarias**:
  ```bash
  make test
  ```

- **Auditoría completa de memoria con Valgrind**:
  ```bash
  make memcheck
  ```

- **Limpiar artefactos generados**:
  ```bash
  make clean
  ```

> [!TIP] **Gestión con `tp.sh`**: Podés utilizar el script interactivo de la cátedra para compilar y probar módulos individuales:
> - `./tp.sh build` — Compila todo el repositorio.
> - `./tp.sh test` — Ejecuta las pruebas de todas las librerías y ejercicios.
> - `./tp.sh test dinamicos` — Prueba únicamente la biblioteca `libdinamicos`.
> - `./tp.sh test ejercicio1` — Prueba únicamente el `ejercicio1`.
