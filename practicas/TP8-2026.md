## Ejercicios

Como mínimo, completar los ejercicios de números pares, incluyendo tests con `lib_test` y `main` interactivo.

### Ejercicio 1: Descomposición Numérica y Aritmética Recursiva

- Archivos: `digitos.h`, `digitos.c`, `main.c`, `prueba.c`.
- **Objetivo**: Dominar la extracción e inducción recursiva sobre órdenes de
  magnitud decimales.
- **Funciones**:
  - `int suma_digitos_recursiva(int n);`
  - `int cantidad_digitos_recursiva(int n);`
  - `int invertir_numero_recursivo(int n);`
- **Pauta algorítmica**: Para un número entero $n \ge 0$, el último dígito se
  obtiene con `n % 10` y el resto con `n / 10`. Manejá números negativos
  mediante su valor absoluto y preservá el signo original en la inversión.

### Ejercicio 2: Procesamiento Recursivo de Cadenas de Texto

- Archivos: `cadenas_rec.h`, `cadenas_rec.c`, `main.c`, `prueba.c`.
- **Objetivo**: Manejar la recursión sobre arreglos terminados en `'\0'`
  mediante aritmética de punteros e índices de extremos.
- **Funciones**:
  - `size_t longitud_recursiva(const char *cadena);`
  - `size_t contar_ocurrencias_recursiva(const char *cadena, char caracter);`
  - `bool es_palindromo_recursivo(const char *cadena);`
- **Pauta algorítmica**: En `longitud_recursiva`, el caso base es
  `*cadena == '\0'`. En `es_palindromo_recursivo`, utilizá una función auxiliar
  con índices `[inicio, fin]` que avance hacia el centro cotejando simetría.

### Ejercicio 3: Búsqueda y Partición en Arreglos (Divide y Conquista)

- Archivos: `arreglos_rec.h`, `arreglos_rec.c`, `main.c`, `prueba.c`.
- **Objetivo**: Aplicar reducción inductiva de tamaño sobre arreglos contiguos y
  división en mitades ($O(\log n)$).
- **Funciones**:
  - `int maximo_arreglo_recursivo(const int *arreglo, size_t n);`
  - `int busqueda_lineal_recursiva(const int *arreglo, size_t n, int objetivo);`
  - `int busqueda_binaria_recursiva(const int *arreglo, size_t inicio, size_t fin, int objetivo);`
- **Pauta algorítmica**: En la búsqueda binaria, calculá el punto medio con
  `inicio + (fin - inicio) / 2` para evitar desbordes aritméticos. Retorná `-1`
  si el intervalo se invierte (`inicio > fin`).

### Ejercicio 4: Recursión de Cola y Acumuladores (Tail Call Optimization)

- Archivos: `recursion_cola.h`, `recursion_cola.c`, `main.c`, `prueba.c`.
- **Objetivo**: Transformar funciones con operaciones pendientes en llamadas de
  cola puras mediante acumuladores de estado.
- **Funciones**:
  - `long long potencia_rapida(long long base, unsigned int exponente);`
  - `unsigned long long fibonacci_cola(unsigned int n);`
  - `int suma_arreglo_cola(const int *arreglo, size_t n);`
- **Pauta algorítmica**: La exponenciación rápida reduce la complejidad a
  $O(\log \text{exponente})$ distinguiendo si el exponente es par o impar. En
  Fibonacci, dos acumuladores `a` y `b` permiten evaluar $F_n$ en tiempo lineal
  $O(n)$ sin la explosión exponencial $O(2^n)$ del árbol ingenuo.

### Ejercicio 5: Algoritmo de Euclides y Problema del Cambio de Monedas

- Archivos: `cambio_monedas.h`, `cambio_monedas.c`, `main.c`, `prueba.c`.
- **Objetivo**: Explorar árboles de decisiones combinatorios donde cada llamada
  genera dos o más subproblemas.
- **Funciones**:
  - `int euclides_mcd_recursivo(int a, int b);`
  - `int contar_formas_cambio(int monto, const int *monedas, size_t cant_monedas);`
- **Pauta algorítmica**: Para dar cambio, en cada paso tenés dos alternativas:
  incluir la moneda actual (restando su valor al monto restante) o descartar la
  moneda actual (avanzando al subarreglo de denominaciones restantes).

### Ejercicio 6: Torres de Hanói con Invariantes y Callbacks

- Archivos: `hanoi.h`, `hanoi.c`, `main.c`, `prueba.c`.
- **Objetivo**: Resolver el clásico problema de $2^n - 1$ pasos notificando cada
  acción elemental a través de punteros a función.
- **Funciones**:
  - `unsigned long long hanoi_contar_movimientos(int discos);`
  - `void hanoi_resolver(int discos, char origen, char auxiliar, char destino, hanoi_callback_t callback, void *contexto);`
- **Pauta algorítmica**: Seguí la secuencia inductiva de 3 pasos: mover $n-1$
  discos al auxiliar, mover el disco mayor a destino mediante el callback, y
  mover los $n-1$ discos desde el auxiliar al destino.

### Ejercicio 7: Estructuras Enlazadas Recursivas (Lista Simplemente Enlazada)

- Archivos: `lista_rec.h`, `lista_rec.c`, `main.c`, `prueba.c`.
- **Objetivo**: Manipular punteros y mutaciones sobre memoria dinámica enlazada
  sin bucles (`while`/`for`).
- **Funciones**:
  - `size_t lista_rec_longitud(const nodo_t *cabeza);`
  - `bool lista_rec_buscar(const nodo_t *cabeza, int valor);`
  - `bool lista_rec_insertar_ordenado(nodo_t **cabeza, int valor);`
  - `void lista_rec_liberar(nodo_t **cabeza);`
- **Pauta algorítmica**: En `lista_rec_insertar_ordenado`, operá sobre el doble
  puntero `nodo_t **cabeza`. Si `*cabeza == NULL` o el valor a insertar es menor
  al del nodo actual, intercalá el nuevo nodo; en caso contrario, llamá
  recursivamente pasando `&((*cabeza)->siguiente)`.

### Ejercicio 8: Backtracking — Exploración y Escape de Laberintos

- Archivos: `laberinto.h`, `laberinto.c`, `main.c`, `prueba.c`.
- **Objetivo**: Implementar avance tentativo y desmarcado de rutas inviables
  sobre grillas bidimensionales.
- **Funciones**:
  - `bool laberinto_resolver(char **mapa, int filas, int columnas, int f_inicio, int c_inicio, int f_salida, int c_salida);`
- **Pauta algorítmica**: Si la celda es transitable (`'.'`), marcala
  temporalmente con `'*'`. Explorá las 4 direcciones. Si alguna llega al
  destino, retorná `true`. Si todas fallan, desmarcala a `'x'`
  (retroceso/backtrack) y retorná `false`.

### Ejercicio 9: Backtracking — Problema de las N Reinas

- Archivos: `reinas.h`, `reinas.c`, `main.c`, `prueba.c`.
- **Objetivo**: Resolver la colocación de $N$ reinas sin ataques mutuos
  utilizando búsqueda exhaustiva con poda.
- **Funciones**:
  - `bool reinas_resolver(int n, int *posiciones);`
  - `int reinas_contar_soluciones(int n);`
- **Pauta algorítmica**: Un arreglo de enteros `posiciones[fila] = columna`
  modela el tablero. Dos reinas $(f_1, c_1)$ y $(f_2, c_2)$ colisionan en
  diagonal si y solo si $|f_1 - f_2| == |c_1 - c_2|$. Podá la rama apenas se
  detecte conflicto.

### Ejercicio 10: Optimización Combinatoria — Problema de la Mochila 0/1

- Archivos: `mochila.h`, `mochila.c`, `main.c`, `prueba.c`.
- **Objetivo**: Resolver el problema clásico de la mochila 0/1 maximizando el
  beneficio total bajo restricción de capacidad.
- **Funciones**:
  - `int mochila_resolver(const int *pesos, const int *valores, size_t n, int capacidad_maxima);`
- **Pauta algorítmica**: Para cada elemento $i$, si su peso excede la capacidad
  restante, descartalo. Si no, calculá recursivamente el máximo entre tomarlo
  ($v_i + \text{mochila}(n-1, W - w_i)$) y no tomarlo
  ($\text{mochila}(n-1, W)$).

## Guía de Compilación, Ejecución y Testing

Podés compilar y probar todo el trabajo práctico desde la raíz del repositorio:

```bash
# Compilar todas las librerías y programas de ejercicios
make

# Ejecutar la suite completa de pruebas unitarias
make test

# Limpiar ejecutables y archivos objeto
make clean
```

También podés trabajar de forma aislada dentro de cada carpeta en
`ejercicios/ejercicioX/`:

```bash
cd ejercicios/ejercicio1
make run        # Ejecuta el programa interactivo main.c
make test       # Ejecuta la suite de pruebas prueba.c
```

O utilizar el asistente interactivo de la cátedra:

```bash
./tp.sh
```
